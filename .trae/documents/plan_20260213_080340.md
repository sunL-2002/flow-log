## FlowLog 桌面应用开发计划

### 技术架构

| 层级   | 技术选型                  |
| ---- | --------------------- |
| 桌面框架 | Tauri 2.x (Rust 后端)   |
| 前端框架 | React 18 + TypeScript |
| 样式方案 | Tailwind CSS          |
| 状态管理 | Zustand               |
| 数据存储 | SQLite (rusqlite)     |
| 窗口监听 | Win32 API             |

### 项目结构

```
flow-log/
├── src-tauri/           # Tauri Rust 后端
│   ├── src/
│   │   ├── commands/    # Tauri 命令
│   │   ├── database/    # SQLite 数据库
│   │   ├── monitor/     # 窗口监听 (Win32 API)
│   │   ├── recognizer/  # 活动识别引擎
│   │   └── tray/        # 系统托盘
│   └── tauri.conf.json
├── src/                 # React 前端
│   ├── components/      # UI 组件
│   ├── pages/           # 页面
│   ├── stores/          # Zustand 状态
│   ├── services/        # Tauri API 封装
│   └── types/           # TypeScript 类型
└── package.json
```

### 开发阶段

**阶段 1**：项目初始化 - 创建 Tauri 项目、配置文件、基础类型

**阶段 2**：Rust 后端核心 - 数据库模块、窗口监听、活动识别、Tauri 命令

**阶段 3**：前端 UI 框架 - 布局组件、通用组件、状态管理

**阶段 4**：核心功能页面 - 时间轴、统计、设置、周报页面

**阶段 5**：系统托盘与通知

**阶段 6**：首次启动引导

### 关键实现细节

1. 窗口监听 ：使用 Windows API 每秒轮询活动窗口，检测变化时触发活动记录
2. 活动合并 ：相同活动类型的连续记录自动合并，设置最小记录间隔（如 30 秒）
3. 规则学习 ：用户修正时可选保存规则，自动应用到未来记录
4. 数据隐私 ：所有数据本地存储，提供数据导出和清空功能
5. 性能优化 ：后台运行时最小化资源占用，前端虚拟滚动处理大量数据

### 核心功能

1. **窗口监听** - Win32 API 获取活动窗口标题
2. **活动识别** - 规则匹配 + 自定义规则学习
3. **时间轴展示** - 按小时分组卡片视图
4. **每日统计** - 专注时长统计与对比
5. **周报生成** - 一键生成可编辑周报
6. **隐私保护** - 本地存储 + 暂停记录
