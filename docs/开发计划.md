## FlowLog 桌面应用开发计划
### 一、项目概述
FlowLog 是一款工作流计时与专注记录器，核心特点：

- 零操作启动 - 后台静默运行，自动识别用户活动
- 智能识别 - 根据窗口标题自动标注活动类型
- 时间轴展示 - 直观的时间轴卡片视图
- 周报生成 - 一键生成周报草稿
- 隐私保护 - 本地数据存储，支持暂停记录
### 二、技术架构
层级 技术选型 说明 桌面框架 Tauri 2.x 轻量级，Rust 后端性能好 前端框架 React 18 + TypeScript 类型安全，生态丰富 样式方案 Tailwind CSS 快速开发，符合设计规范 状态管理 Zustand 轻量级，适合桌面应用 数据存储 SQLite (rusqlite) 本地数据库，查询高效 窗口监听 Win32 API 获取活动窗口标题

### 四、核心模块实现 1. Rust 后端模块
窗口监听模块

- 使用 Win32 API GetForegroundWindow 获取活动窗口
- 使用 GetWindowTextW 获取窗口标题
- 定时轮询（间隔可配置，默认 1 秒）
- 窗口切换事件检测与防抖处理
活动识别模块

- 预设规则：VS Code/IDEA -> 编码，钉钉/微信 -> 沟通，腾讯会议/Zoom -> 会议
- 自定义规则支持
- 置信度计算（完全匹配 > 部分匹配 > 无匹配）
- 规则学习与保存
数据存储模块

- SQLite 数据库表结构：
  - activities - 活动记录表
  - recognition_rules - 识别规则表
  - daily_stats - 每日统计缓存表
  - app_settings - 应用设置表
- 数据迁移策略
系统托盘模块

- 状态图标切换（记录中/暂停/专注）
- 右键菜单
- 悬停提示 2. React 前端模块
时间轴视图

- 按小时分组显示活动卡片
- 卡片展开/收起详情
- 快速修正功能
- 低置信度提示
统计视图

- 今日/本周/本月统计
- 时间分配饼图/条形图
- 趋势对比
- 洞察建议
周报生成

- 自动聚合本周活动
- 可编辑调整
- 多格式导出（文本/Markdown）
- 一键复制
设置页面

- 隐私设置（开机启动、暂停记录）
- 识别规则管理
- 通知设置
- 外观设置（深色/浅色主题）

### 六、关键实现细节
1. 窗口监听 ：使用 Windows API 每秒轮询活动窗口，检测变化时触发活动记录
2. 活动合并 ：相同活动类型的连续记录自动合并，设置最小记录间隔（如 30 秒）
3. 规则学习 ：用户修正时可选保存规则，自动应用到未来记录
4. 数据隐私 ：所有数据本地存储，提供数据导出和清空功能
5. 性能优化 ：后台运行时最小化资源占用，前端虚拟滚动处理大量数据
