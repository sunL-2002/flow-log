# 工作流计时与专注记录器（FlowLog）
## 场景痛点
每天感觉忙了一天，但复盘时想不起来干了什么。想用番茄钟又嫌切换太频繁，手动记录又坚持不下来。

## 工具形态
后台默默运行，通过窗口标题、输入停顿推测你在做什么。

## 核心功能

### 自动标注活动：

- 窗口标题含“IDE”“VS Code” → 编码

- 窗口含“钉钉”“微信”且发言频率低 → 待命

- 窗口含“腾讯会议”“Zoom” → 开会

### 静默时间轴：按小时生成一张卡片，写明“14:00 - 15:20 开发登录模块”，可手动修正。

### 每日积分：不是惩罚型监控，而是正向反馈——“今天专注写代码3小时，比昨天多30分钟”。

### 周报草稿：一键把这一周的时间轴合并成几段文本，复制到周报里直接改。

## 一句话亮点
“比你自己更清楚你今天到底干了什么。”
