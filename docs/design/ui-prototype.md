# FlowLog UI 原型设计文档

## 设计原则

1. **零操作启动** - 用户无需任何操作即可开始记录
2. **认知负荷最小** - 默认只显示核心信息，细节按需展开
3. **正向反馈优先** - 强调成就而非惩罚
4. **隐私透明** - 让用户清楚知道什么被记录了
