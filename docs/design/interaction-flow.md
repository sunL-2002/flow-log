# FlowLog 交互流程设计文档

## 概述

本文档描述 FlowLog 的核心交互流程，包括用户操作流程、状态转换、错误处理等。

---

## 一、应用启动流程

### 1.1 首次启动流程

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   启动应用   │────▶│  检查是否   │────▶│  显示欢迎   │────▶│  请求权限   │
│             │     │  首次启动   │     │    页面     │     │             │
└─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘
                                                                  │
                           ┌──────────────────────────────────────┘
                           ▼
                    ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
                    │  权限是否   │────▶│  显示基础   │────▶│  后台运行   │
                    │    授予     │     │  设置页面   │     │  最小化     │
                    └─────────────┘     └─────────────┘     └─────────────┘
                           │
                           │ 拒绝
                           ▼
                    ┌─────────────┐
```

## 八、交互细节规范

### 8.1 反馈时机

| 操作 | 反馈类型 | 延迟 |
|-----|---------|------|
| 点击按钮 | 视觉反馈 | 立即 |
| 保存设置 | Toast 提示 | < 500ms |
| 导出数据 | 进度条 + 成功提示 | 根据数据量 |
| 修正标签 | 内联更新 + 微动画 | < 200ms |
| 切换日期 | 加载动画 | < 300ms |

### 8.2 防抖与节流

| 场景 | 处理方式 | 时间间隔 |
|-----|---------|---------|
| 窗口切换检测 | 防抖 | 500ms |
| 搜索过滤 | 防抖 | 300ms |
| 滚动加载 | 节流 | 200ms |
| 输入频率检测 | 节流 | 1000ms |

### 8.3 确认对话框

| 操作 | 是否需要确认 | 确认文案 |
|-----|-------------|---------|
| 删除单条记录 | 否 | - |
| 删除当天数据 | 是 | "确定删除今天的所有记录吗？" |
| 清空所有数据 | 是 | "确定清空所有数据？此操作不可恢复！" |
| 重置设置 | 是 | "确定恢复默认设置？" |
| 退出应用 | 否 | - |
