# FlowLog 图标目录

此目录存放应用图标文件。

## 需要的图标文件

- `icon.ico` - Windows 应用图标 (256x256)
- `icon.png` - 默认图标 (1024x1024)
- `32x32.png` - 32x32 像素图标
- `128x128.png` - 128x128 像素图标
- `128x128@2x.png` - 256x256 像素图标（高 DPI）
- `icon.icns` - macOS 应用图标

## 图标设计建议

- 使用简洁的设计，代表时间追踪或专注工作
- 主色调：#4A90D9（品牌蓝色）
- 在小尺寸下仍清晰可辨

## 生成图标

可以使用以下工具生成图标：
- [Tauri Icon Generator](https://github.com/tauri-apps/tauri/tree/dev/tooling/cli/templates/app/app-icon.png)
- [Icon Generator](https://www.xiconeditor.com/)
